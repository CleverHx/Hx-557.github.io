博客重新开始

这个仓库已经清理成一个干净的静态个人博客，可以直接通过 GitHub Pages 发布访问。

过去仓库里有 Hexo 生成的旧页面和资源。现在保留最简单、最容易维护的结构：一个首页、一个文章目录、 一份样式文件和 GitHub Pages 所需的 `.nojekyll` 文件。

后续添加文章时，只需要在 `posts/` 目录新增 HTML 文件，并在首页的“最新文章”列表里添加入口即可。

下一步计划

  • 整理博客主题和个人介绍。
  • 持续发布技术学习和项目记录。
  • 如果文章变多，再迁移到 Astro、Hugo 或 Hexo 等静态站点生成器。
